# Changelog

## 0.1.0-SNAPSHOT

- Added Minecraft-independent foundation API and per-server context lifecycle.
- Added typed service registry with logical-ID uniqueness, deterministic
  health snapshots, and lock-free external callbacks.
- Added exact protocol/train handshake, bounded packet codec, native System
  Status menu, server-side permission projection, sessions, deltas, and
  recovery command.
- Added Forge 47.4.10 Jar-in-Jar packaging, GameTest holder, reproducibility,
  source policy, dependency verification, and role-aware runtime SBOM.
- Audit persistence and all gameplay/database features remain intentionally
  unimplemented.
